# Irispectra Atlas

An immersive, offline-capable (once loaded) static prototype for the IRISPECTRA personalized iris explorer.

## Features
- Procedural sample iris artwork, generated by the browser on a 2D canvas.
- 2.5D pointer-controlled rotation, wheel/slider zoom, interactive anatomical hotspots.
- Detailed inspection viewer with pan and zoom.
- Local image upload with manual iris alignment, browser-only processing.
- PNG artwork export.
- Responsive mobile layout, reduced motion consideration, semantic descriptions.

## Run locally

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

## Deploy on Vercel

Vercel Dashboard → Add New → Project → choose **Deploy** / **Upload** and select this directory (or import via a new GitHub repo). No build command, runtime, API keys or environment variables are required. Framework preset: **Other**. Output directory: project root.

## Important limitations

This is a design and interaction prototype. It **does not** automatically segment irises, infer diseases, read biometric identity, or generate a validated clinical report. A user's uploaded image is aligned manually. The sample iris is illustrative procedural art, not biological data. The uploaded image stays in the browser and is not sent to a server by the code in this prototype.
